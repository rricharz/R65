MILL MOVE double-threat regression tests
========================================

millneg2.txt and millpos2.txt are saved Nine Men's Morris positions used
to test MOVE-phase double-mill-threat detection.

Both positions are loaded immediately before the same White move:

    C5-C4

After this move, the computer (Black) calls blockdouble(), which uses
doublethreat(WHITE).

millneg2.txt
------------
Negative test.

The hypothetical White move B4-A4 appears geometrically to create two
possible bridges:

    A1-A4-A7
    A4-B4-C4

However, only B4 is a genuinely reachable bridge position (B6-B4).
A7 can only be reached by moving A4, which would destroy A1-A4-A7.

Expected result:

    doublethreat(WHITE) = FALSE
    no "DOUBLE MOVE B4-A4" message

millpos2.txt
------------
Positive test.

This is an artificial variant in which White has a stone at D7, making
both bridge positions genuinely reachable after B4-A4:

    D7-A7 completes A1-A4-A7
    B6-B4 completes A4-B4-C4

Expected result:

    doublethreat(WHITE) = TRUE
    "DOUBLE MOVE B4-A4" is reported

Purpose
-------
Together these files test that reachablethreats() does not merely count
geometrical mill-closing positions during MOVE. A threat counts only if
a legal move can reach the closing position while leaving the completed
mill intact.
