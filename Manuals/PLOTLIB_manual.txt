PLOTLIB – R65 Tiny Pascal Plot Library
======================================

NAME
----
```
plotlib – graphics support library for R65 Tiny Pascal
```

SYNOPSIS
--------
```
library plotlib;
```

DESCRIPTION
-----------
The **plotlib** library provides a set of primitive graphics
routines for programs written in R65 Tiny Pascal.  It offers
functions to initialise and terminate the graphics subsystem,
plot individual pixels, draw lines, display small bitmaps, and
wait for a key press.  All routines operate directly on the
hardware of the R6 microcomputer and use the global variables
and memory–mapped registers declared in the library.

The coordinate system is 0 ≤ *x* ≤ XSIZE and 0 ≤ *y* ≤ YSIZE,
where `XSIZE = 223` and `YSIZE = 117`.  Colour values are given
by the constants **WHITE**, **INVERSE** and **BLACK**.  A global
pointer **PLOTDEV** points to the graphics device.

CONSTANTS
---------
* `XSIZE = 223` – maximum horizontal coordinate (0 – 223)
* `YSIZE = 117` – maximum vertical coordinate (0 – 117)
* `XWORDS = 28` – words per scan–line (for internal use)
* `WHITE = 0` – colour value for white pixels
* `INVERSE = 1` – colour value for inverse video
* `BLACK = 2` – colour value for black pixels
* `PLOTDEV = @128` – file descriptor for the graphics device

SYSTEM VARIABLES
----------------
```
KEYPRESSED ($1785) : char&    – last typed key, if any
_xcursor, _ycursor : integer  – internal current cursor position
```
The variables `_xcursor` and `_ycursor` remember the last
plotted or moved position.  `KEYPRESSED` reflects the most
recent key typed on the keyboard and is polled by the
`_waitforKEY` routine.

PROCEDURES AND FUNCTIONS
------------------------
### `_delay10msec(time: integer);`

Suspend the process for approximately *time* × 10 milliseconds.
This routine writes the value 6 into the system register
`emucom` (*$1430*) in a loop.  It may be used to pace animations
or to create short delays.

### `_syncscreen: integer;`

Synchronise the display refresh and return the sleep time since
the last sync in milliseconds.  Writing 7 into `emucom` causes
the hardware to update the video memory; the result is then
returned from `emures` (*$1431*) as the function result.  The
return value is between 0 and 30 ms.

### `_grinit;`

Initialise the graphics subsystem.  This calls the
system routines at $E01E and $E016 to set up the graphics
display and the CRT timing.  A message is printed instructing
the user that `Ctrl‑T` toggles the canvas size and `GREND` closes
the graphics window.

### `_grend;`

Terminate the graphics subsystem and restore the alpha display.
This calls the routine at $E01B and sets the Pascal flag in
`sflag` (*$1781*).  After calling `_grend` the program should
output text using the normal console routines.

### `_cleargr;`

Clear the entire graphics display.  Calls a system routine at
$E231 to erase the screen.

### `_fullview;`

Switch to full screen graphics mode.  This calls the routine
at $E016 to allocate the entire display for graphics (no text
window).

### `_splitview;`

Switch to a split view, where the display is divided between
graphics and a small text window.  Calls the routine at $E015.

### `_plot(x, y, c: integer);`

Plot a single pixel at coordinates (*x*, *y*) using colour *c*.
Values outside the range 0 ≤ *x* ≤ XSIZE and 0 ≤ *y* ≤ YSIZE
are clipped to the nearest valid coordinate.  The routine
assigns `_xcursor := x`, `_ycursor := y`, writes *x*, *y* and *c*
into the memory–mapped registers (*$03AE–$03B0*) and calls the
system routine at $C815 to set the pixel.

### `_move(x, y: integer);`

Move the graphics cursor to (*x*, *y*) without drawing.  As in
`_plot`, the coordinates are clipped to the graphics area and
written into the registers at $03AE and $03AF.  The global
variables `_xcursor` and `_ycursor` are updated accordingly.

### `_draw(x, y, c: integer);`

Draw a straight line from the current cursor position
(`_xcursor`, `_ycursor`) to (*x*, *y*) in colour *c*.  The
endpoints are clipped to the graphics area.  For horizontal
or vertical lines the routine calls fast helper routines
`_drawx` or `_drawy`.  Diagonal and oblique lines are drawn by
interpolating a step in *x* and *y* and calling the system
routine at $C824.  After drawing, `_xcursor` and `_ycursor`
are set to the new endpoint.

### `_plotmap(x, y, m: integer);`

Plot a 4×4 bitmap at coordinates (*x*, *y*).  The integer *m*
contains 16 bits: bit 15 (most significant) corresponds to the
top left pixel, bit 0 to the bottom right pixel.  If *x* or *y*
are outside the valid range the bitmap is clipped to the
graphics area.  The routine writes the coordinates and the
bitmap into registers and calls the system routine at $C81B.

### `_waitforKEY;`

Wait until a key is pressed.  The routine reads from the
unbuffered keyboard device (file `KEY` = @1) until the next
character differs from the toggle character (`Ctrl‑L`).  During
the wait it echoes the toggle character back to the display.
This call does not return the pressed key; it merely pauses
execution until a key is typed.
