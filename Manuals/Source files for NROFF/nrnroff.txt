.TH NROFF(1)

.SH NAME
nroff - small text formatter for R65 Pascal

.SH SYNOPSIS
.PP
nroff reads a text file containing ordinary text and
simple formatting requests. It writes formatted output
to @PRINTER.

.SH DESCRIPTION
.PP
This nroff is a small practical formatter for manuals
on the R65 system. It is not Unix nroff and does not
try to support the full historical request set.

.PP
Its purpose is to format plain text manuals into
readable paged output suitable for later printing or
conversion on a modern system.

.PP
Ordinary text is formatted in fill mode. In this mode,
input lines are combined into paragraphs and wrapped to
the current line length.

.PP
No-fill mode is used for literal text, examples, and
program fragments. In this mode, input lines are
written as they stand.

.PP
Formatting requests begin with a dot in column 1.
Request names are not case sensitive. Many requests
take no argument. For such requests, any extra text on
the same line is an error.

.SH BASIC RULES
.PP
A request line begins with a dot followed by a two
letter request name.

.PP
Example:
.PP
In the following example, each source line is shown
with a leading '> ' for clarity. The '> ' characters
are not part of the actual input file.
.PP
.nf
> .PP
> .SH NAME
> .SP 2
> .LL 55
.fi

.PP
Ordinary text lines do not begin with a dot.

.PP
In fill mode, repeated blanks in the source are
collapsed to a single blank between words.

.PP
Blank vertical space is usually inserted with .SP
rather than by empty source lines.

.PP
To show request lines in examples, prefix them with a
blank so they are not interpreted.

.SH REQUESTS
.SS .TH title
.PP
Starts a new page and sets the page header text.

.PP
On page 1, the new page begins without a form feed.
On later pages, a form feed is written first.

.PP
A bare .TH starts a new page and turns headers off.

.SS .SH text
.PP
Prints a major section heading in uppercase followed
by an underline of '=' characters.

.SS .SS text
.PP
Prints a subsection heading in uppercase followed by
an underline of '-' characters.

.SS .PP
.PP
Starts a new paragraph.

.SS .BR
.PP
Breaks the current output line.

.SS .NF
.PP
Enters no-fill mode. Input lines are then copied
literally.

.SS .FI
.PP
Returns to fill mode.

.SS .SP
.PP
Inserts one blank output line.

.SS .SP n
.PP
Inserts n blank output lines.

.SS .LL
.PP
Resets the line length to the default value.

.SS .LL n
.PP
Sets the line length to n characters.

.SS .IP text
.PP
Starts an indented paragraph with a hanging tag.

.PP
If the tag is short, the body text begins on the same
line. If the tag is long, the body begins on the next
line at the item indentation.

.SS .RS
.PP
Starts a relative indent.

.SS .RE
.PP
Ends a relative indent.

.SS .B text
.PP
Writes one line directly. The text argument is
required.

.SS .I text
.PP
Writes one line directly. The text argument is
required.

.SH EXAMPLE
.PP
A small input example:
.PP
In the following example, each source line is shown
with a leading '> ' for clarity. The '> ' characters
are not part of the actual input file.
.PP
.nf
> .TH TEST(1)
> .SH NAME
> test - sample manual
> .SH DESCRIPTION
> .PP
> This is a short paragraph in fill mode.
> .SP 1
> .NF
> literal line 1
> literal line 2
> .FI
> .IP item
> This is the text of the item.
.fi

.SH ERRORS
.PP
If a request has bad syntax, nroff reports the source
line, marks the error position with '^', and prints the
source line number.

.PP
After too many errors, processing stops.

.SH LIMITATIONS
.PP
This formatter is intentionally small.

.PP
It supports only a useful subset of requests.

.PP
Output is plain ASCII text written to @PRINTER.

.PP
There is no true bold or italic output. Such effects
may later be added on the modern system when the text
is converted to PDF.

.PP
Long words are not hyphenated.

.PP
This program is meant for practical manual production
on the R65 system, not for complete compatibility with
Unix nroff.

.SH AUTHOR
.PP
This formatter was developed for the R65 Pascal system
as a small and maintainable manual tool.
