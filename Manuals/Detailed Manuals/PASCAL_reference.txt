R65 PASCAL – R65 PASCAL LANGUAGE AND SYSTEM
===========================================

SYNOPSIS
--------
    R65 Pascal is a structured programming language
    and compiler for the R65 6502‑based system.
    Programs are entered in plain text, compiled with
    the compile command and executed by the Pascal
    environment.  The command syntax is:

        COMPILE filename

    where filename is the source file without
    extension :P
    Object code is emitted to a :R file
    and symbol information may be placed in a
    library.  Use filename to execute the compiled
    code.

    Libraries are compiled separately but included
    in the object code. They may not be nested and do
    not share any information.

DESCRIPTION
-----------
    R65 Pascal is a subset of early Pascal.  It
    supports structured programming with procedures,
    functions and lexical scope.  Compilation is single
    pass; there is a short second phase which handles
    forward jumps. The compiler generates code for the
    P-Code engine which is written in Assembler for the
    6502 processor.  Identifiers are case‑insensitive
    and only the first eight characters are
    significant.

    Programs are composed of blocks; each block may
    contain constant definitions, memory declarations,
    variable declarations, procedure/function
    declarations and a statement part.  Comments are
    enclosed in curly braces { ... } and may not be
    nested. The brackets are required to be on the
    same line.

DATA TYPES
----------
    R65 Pascal provides the following predefined types:

    * boolean
          Truth values true and false.

    * integer
          16‑bit signed integers in the range
          –32768 to 32767.

    * char
          8‑bit character values.  Characters are
          enclosed in single quotes, e.g. 'A', or
          chr(13) for carriage return.

    * real
          32‑bit floating point values.  Real literals
          use the form 1.23E4 or '12.345'

    * file
          File variables for text and binary I/O.
          Several variables are predefined: INPUT,
          OUTPUT, KEY, PRINTER and PLOTTER. Sequential
          files can be opened and read from or written
          to.

    * cpnt (heap pointers)
          A pointer type used to reference heap memory. 
          These pointers are manipulated via intrinsic
          functions and procedures.

    * Strings
          R65 Pascal has no native string type;
          strings are arrays of char. String constants
          may be assigned to array variables. Arrays of
          char are 16-bit per element. Strings on the
          heap are handled with pointers and are 8-bit
          per element plus end mark (0).

USER TYPES
----------
    User‑defined types are not supported. Records and
    sets are not provided.

    * Arrays

          Syntax: array[n] of element_type. Element
          type can be any available by Pascal.
          Arrays start with index 0 and stop with
          index n. This means that their size is n+1
          elements. Only one dimensional arrays are
          allowed. Even arrays of char occupy 16 bit
          per element. Real numbers occupy 32 bit
          per element.
    

DECLARATIONS
------------
    A block begins with optional declarations.
    Declarations are terminated by semicolons.
    Sections must appear in the following order:

    1. **Const section**: introduces named constants.

            const
              maxrows = 24;
              pi      = 3.14159;
              ENDMARK = chr(0);

    2. **Memory section**: accesses static memory and 
       hardware registers for the memory mapped I/O

            mem
              buffer =address: array[255] of char&;
              c=address: char&;
              x=address: integer;

       Here 8-bit chars are allowed and 8-bit integers.
       The symbol & identifies 8-bit memory cells.

    3. **Var section**: declares local variables.

            var
              row, col: integer;
              name: array[8] of char;

    4. **Procedure and function declarations**: define
       subroutines.  Procedures have no return value;
       functions return a value of the specified type.

            procedure draw_line(j: integer);
            var i: integer;
            begin
              for i := 0 to j do
                screen[t] := '*';
            end;

            function max(a, b: integer): integer;
            begin
              if a > b then
                max := a
              else
                max := b;
            end;

    Each declared identifier may be referenced in the
    block following its declaration.  Identifiers are
    scoped; inner declarations hide outer ones.
    Shadowing is not allowed if the {$U-} compiler
    directive is used.


STATEMENTS
----------
    After declarations, the block concludes with a
    statement part.  Statements are executed
    sequentially unless controlled by flow‑control
    structures.

    * **Assignment**:  variable := expression;

    * **Compound statement**:  begin ... end

    * **Conditional**:  if condition then statement
      [else statement]

    * **Case statement**:  case expr of value1: stmt;
      value2: stmt; ...value5: stmt end;
      The last statement must not have a semicolon.

    * **While loop**:  while condition do statement

    * **Repeat loop**:  repeat statement; ... 
       until condition;

    * **For loop**:  for variable := start to finish
       do statement

    * **Procedure/function call**:
      procedure_name(actuals); or
      result := function_name(actuals);

    * **Block**:  an inner block may appear wherever a
      statement is allowed.


EXPRESSIONS
-----------
    Expressions may contain literals, variables and
    calls to functions.  The usual arithmetic and
    boolean operators apply.  The order of evaluation
    follows Pascal precedence: parentheses, unary
    plus/minus, multiplication/division, and
    addition/subtraction.

    Relational operators are =, <>, <, <=, >,
    >=. Logical operators are and, or, not for
    booleans.

INPUT AND OUTPUT
----------------
    Input and output are performed with built‑in
    procedures.

    * read(var, ...) and readln(var, ...)
          Read values from INPUT.  Reading a string
          reads up to a blank or newline. readln
          discards the rest of the line.  Input also
          reads from open sequential Files.

    * write(expression, ...) and
      writeln(expression, ...)
          Write values to the default output device.
          writeln appends a carriage return (13)
          and line feed (10).  To write to a specific 
          device, provide a file variable as first
          parameter, e.g. writeln(@PRINTER, value);.

          Arrays of characters may be written by
          iterating over their elements.


RUNTIME LIBRARY
---------------
    The compiler supplies several intrinsic procedures
    and functions in addition to read and write:

    * succ(x) and pred(x)
          Return the successor or predecessor of an
          ordinal value.

    * odd(x)
          Returns true if x mod 2 = 1.

    * _new and _release
          Allocate and release storage on the heap.
          Pointers returned by new must be of type
          cpnt which is a pointer to an array of
          char.

    * ord(x) and chr(x)
          Convert between ordinal types and integers
          or characters.

    * _abort
          halt terminates the program.

    * _time and _date functions
          Return the current system time or date.

    * exit from procedures or functions
          Terminates the current procedure or function
          and returns to the caller. The procedures and
          function starting with _ are supplied by
          libraries.


MEMORY MODEL AND LIMITATIONS
----------------------------
    * **Identifier length**:  Only the first eight
      characters of an identifier are significant.
      Names longer than 8 characters are permitted
      but truncated for uniqueness.

    * **Static allocation**:  Variables and arrays are
      statically allocated.  Dynamic allocation is
      restricted to character arrays via new.
      There is no garbage collection; allocated blocks
      must be freed with free in reverse order.

    * **Only procedures and functions may be declared
      forward. 
 
    * **No record type**:  Records and sets are not
      supported.

    * **Single pass**:  The compiler processes source
      in one pass.  Therefore forward references to
      variables are not permitted; constants must be
      defined before use.  Only procedure/function
      declarations may be forwarded.

    * **System directives**:  Compiler directives are
      lines starting with {$ and supply compile‑time
      options.

EXAMPLE PROGRAM
---------------
    The following program reads characters from the
    keyboard until a full line is entered and then
    prints the line on the printer:

        program echo;
        const max = 32;
        var  buf: array[max] of char;
             len: integer;
             ch:  char;
        begin
          len := 0;
          repeat
            read(ch);
            if (len < max) and (ch <> chr(13)) then
            begin
              len := succ(len);
              buf[len] := ch;
            end;
          until ch = chr(13);
          writeln(@PRINTER);
          for len := 1 to len do
            write(@PRINTER, buf[len]);
          writeln(@PRINTER);
        end.
