MATHLIB – R65 Pascal mathematics library
========================================

NAME
----
MATHLIB – Real math functions and I/O routines for
          R65 Pascal

SYNOPSIS
--------
```
program test;
    uses mathlib;
    var r: real;
begin
    r := sqrt(2.0);
    writefix(OUTPUT, 3, r);
    writeln;
end.
```

DESCRIPTION
-----------
**MATHLIB** supplies real mathematics functions and
real number output routines for the R65 Pascal system. 
It is intended for programs that require floating‑point
calculations such as square roots, trigonometric
functions and exponential/logarithmic calculations.
The library also contains procedures to print
floating‑point values in fixed or exponential notation.

The library defines two named constants:

* `PI = 3.14159` – the value of π.
* `E  = 2.71828` – the base of the natural logarithm.

CONSTANTS
---------
* **PI** = 3.14159 – used internally by the
  trigonometric functions and available to the user.
* **E**  = 2.71828 – Euler’s number, used in the
  logarithmic and exponential functions.

PROCEDURES AND FUNCTIONS
------------------------
MATHLIB provides functions to operate on `real` values
and procedures to output real numbers.  Unless
otherwise noted, arguments and results are of type
`real`.

### Real Functions

* `func fabs(x: real): real;`

  Returns the absolute value of `x`.  If `x < 0` the
  negative is returned, otherwise `x` is returned
  unchanged.

* `func sqrt(n: real): real;`

  Computes the square root using a Newton
  approximation.  If `n = 0.0` the result is `0.0`;
  if `n < 0.0` an error message is printed (“sqrt(x)
  for x<0 called”) and `0.0` is returned.  A
  relative accuracy of about 1×10⁻⁴ is used.

* `func cos(x: real): real;`

  Returns the cosine of `x` degrees.  Arguments are
  taken in degrees and reduced into the 0–360° range.
  Special cases for 0, 90 and 180° are handled
  explicitly.  Values in other quadrants are mapped
  appropriately.  A helper routine `cos0` computes
  cosine using its Taylor series.

* `func sin(x: real): real;`

  Computes the sine of `x` degrees by calling
  `cos(x-90)`.

* `func tan(x: real): real;`

  Returns the tangent of `x` degrees.  If `cos(x)`
  is zero (approximately 90°), an error message
  (“tan(90) undefined”) is printed.  The function
  returns a very large value `1.0e+38` or its negative
  to indicate an undefined tangent.

* `func ln(r: real): real;`

  Calculates the natural logarithm of `r`.  If `r` is
  close to 1.0 the result is 0.0.  If `r <= 0.0` an
  error (“ln(x) for x<=0 called”) is printed and a tiny
  negative number is returned to indicate an error.
  Internally it uses exponent extraction
  and a series expansion for better precision.

* `func exp(x: real): real;`

  Returns *e*ˣ.  The argument `x` is reduced to the
  range ±ln2 and a series expansion is used. Powers of
  two are re‑inserted into the result.  For negative
  arguments the reciprocal is returned.

* `func log(x: real): real;`

  Computes the base‑10 logarithm as `ln(x)*0.434294`.
  If `x` is close to 10.0 the result is approximately
  1.0.

### Real Output

These procedures produce formatted real numbers on a
specified file.

* `proc writeflo(f: file; r: real);`

  Writes the real `r` to the file `f` in exponential
  notation. The number occupies 11 characters with 3
  digits after the decimal point.  Leading blanks and a
  possible negative sign are included.

* `proc writefix(f: file; d: integer; r: real);`

  Writes `r` to the file `f` in fixed‑point format.
  The result occupies 11 characters, right aligned.
  `d` specifies the number of digits after the decimal
  point;  The floating‑point accuracy of the R65
  implementation is approximately 5 digits.

* `proc writef0(f: file; d: integer; r: real;
  fl: integer; centered: boolean);`

  Low‑level helper used by `writefix`.  Writes `r`
  in fixed format to a field of width `fl` characters.
  If `centered` is *true*, the number is centred in
  the field; otherwise it is right aligned.  Digits
  after the decimal point are limited to three.

* `func readflo(f: file): real;`

  Reads a real number from the file `f`.  It supports
  optional signs (`+` or `-`), integer and fractional
  parts, and an optional exponent (`E` or `e` followed
  by a signed integer). The value is returned as a
  `real`.
