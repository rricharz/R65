STRLIB - STRING HANDLING FOR CPNT POINTERS
==========================================

SYNOPSIS
--------
library strlib;

DESCRIPTION
-----------
STRLIB provides basic string handling routines for type cpnt.

Type cpnt denotes a pointer to a 0-terminated string with a
maximum length of 64 characters. The terminating byte is chr(0).

Strings are allocated in heap memory and managed in a stack-like
fashion.

CONSTANTS
---------
STRSIZE
     Maximum number of characters in a string (excluding terminator).
     Value: 64.

ENDMARK
     String terminator.
     Value: chr(0).

MEMORY MODEL
------------
Strings are allocated from heap memory below ENDSTK.

Allocation and release follow a strict LIFO discipline:
only the most recently allocated string can be released.

This model is efficient and well suited for recursive routines.

FUNCTIONS AND PROCEDURES
------------------------

_runerr(e: integer)
     Abort execution with runtime error code e.

_new: cpnt
     Allocate memory for a new string.
     The result is initialized to an empty string.

_release(s: cpnt)
     Release memory previously allocated by _new.
     Only valid if s is the most recently allocated string.

_strlen(strin: cpnt): integer
     Return the length of strin.

_strcpy(strin, strout: cpnt)
     Copy strin to strout.

_stradd(strin, strinout: cpnt)
     Append strin to strinout.

_strcmp(s1, s2: cpnt): integer
     Compare two strings lexicographically.
     Returns:
         -1  if s1 < s2
          0  if s1 = s2
          1  if s1 > s2

_strpos(ch: char; s1: cpnt; start: integer): integer
     Return index of first occurrence of ch in s1 starting
     at position start.
     Returns -1 if not found.

_strread(f: file; s: cpnt): integer
     Read characters from file f into s.
     Reading stops when one of the following occurs:
         carriage return (chr($0D))
         EOF marker      (chr($1F))
         rubout          (chr($7F))
         NUL             (chr(0))
         maximum length reached
     The string is always terminated with chr(0).
     Returns number of characters read.

_hexstr(d: integer; s: cpnt)
     Convert byte value d into a two-character hexadecimal string.

_strinsc(ch: char; pos: integer; s: cpnt)
     Insert character ch at position pos.
     If pos exceeds current length, the gap is filled with blanks.
     Generates runtime error if string would overflow or pos is invalid.

_strdelc(pos: integer; s: cpnt)
     Delete character at position pos.

_intstr(n: integer; s: cpnt; fsize: integer)
     Convert integer n to string.
     Result is right-justified in a field of width fsize.

ERRORS
------
$88
     Insufficient heap space.
     256 words are reserved for stack growth.

$91
     Invalid insertion or resulting string too long.

$92
     Invalid release (not the most recently allocated string).

NOTES
-----
_strlen stops at ENDMARK or after STRSIZE characters.

_strcpy and _stradd internally use write(@...) for copying.

_strread always writes a terminating chr(0) after input.

_hexstr produces uppercase hexadecimal digits.

_intstr pads the result with leading blanks as required.

LIMITATIONS
-----------
Maximum string length is fixed at 64 characters.

Memory management is strictly LIFO; arbitrary freeing is not supported.

Strings are 0-terminated and intended for compact internal use.
