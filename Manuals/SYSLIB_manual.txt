SYSLIB – R65 SYSTEM LIBRARY
===================================

SYNOPSIS
--------
`uses syslib;`

DESCRIPTION
-----------
The **system library** `syslib` provides a set of predefined constants, variables and
auxiliary routines used by the R65 Pascal compiler and runtime.  Many of
the symbols defined here interface directly with the underlying R6
microcomputer hardware.  Programs need to include the library with a
`uses` statement.  The library was originally written in 1982 and is maintained for
backwards‑compatibility; version 12.0 (3 September 2018) adds the
function `random`.

CONSTANTS
---------
The following named constants represent control characters or system
limits.  They may be used anywhere a character or integer constant is
required.

- `TAB8`  = `chr(9)` – horizontal tab.
- `HOM`  = `chr(1)` – cursor home.
- `CSC`  = `chr($11)` – clear screen.
- `LF`   = `chr($0A)` – line feed.
- `FF`   = `chr($0C)` – form feed (page break).
- `CR`   = `chr($0D)` – carriage return.
- `EOF`  = `chr($7F)` – end of file character.
- `NORVID` = `chr($0B)` – normal video attribute.
- `INVVID` = `chr($0E)` – inverse video attribute.
- `PRTON` = `chr($12)` – enable autoprint (obsolete; see printing).
- `PRTOFF`= `chr($14)` – disable autoprint.
- `MMAXSEQ` = 8 – maximum number of sequential files.
- `TOPMEM`  = `$C780` – top of user memory.
- `MAXINT`  = `$7FFF` – maximum value of 16‑bit signed integers.
- `INPUT`  = `@0` – line buffered keyboard input file.
- `OUTPUT` = `@0` – display output file.
- `KEY`    = `@1` – unbuffered keyboard input file.
- `PRINTER`= `@1` – hard copy output file.

SYSTEM VARIABLES
----------------
The following `mem` variables map directly onto processor memory and
hardware registers.  They should be treated as read‑only unless
documented otherwise.

- `RUNERR` `=$000C`: integer& – current runtime error code.  Set
  by the system when an unrecoverable error occurs.
- `ENDSTK` `=$000E`: integer – end of stack pointer.
- `BUFFPN` `=$0015`: integer& – pointer into input buffer.
- `IOCHECK` `=$0023`: boolean& – result of last I/O operation; `true`
  indicates success.
- `MUMARG` `=$005F`: integer& – number of command‑line arguments.
- `ARGLIST` `=$0060`: array[31] of integer – addresses of argument strings.
- `ARGTYPE` `=$00A0`: array[31] of char& – argument types.
- `FILFLG` `=$00DA`: integer& – file status flags.
- `FILDRV` `=$00DC`: integer& – current drive number.
- `CURPOS` `=$00EE`: integer& – current cursor column on the display.
- `FILNUM` `=$0301`: array[15] of char& – name of currently open file.
- `FILNM1` `=$0320`: array[15] of char& – secondary file name.
- `FILCYC` `=$0311`: integer& – current file cycle count.
- `FILCY1` `=$0330`: integer& – first cycle count.
- `MAXSEQ` `=$0336`: integer& – maximum sequence number for
  sequential files.
- `FIDRTP` `=$0339`: array[MMAXSEQ] of integer& – pointers to
  file descriptors.
- `_day`, `_month`, `_year`: integer – global variables filled
  by `_getdate` representing the current day, month and year.

& refers to 8-bit data.

PROCEDURES AND FUNCTIONS
------------------------
All procedures and functions in `syslib` are prefixed with an
underscore to avoid collisions with user identifiers.  Unless
otherwise noted, procedures do not return a value (`proc`), and
functions (`func`) return a 16‑bit integer.

### Runtime and system control

- `proc _setemucom(i: integer)` – Write a command into the emulator
  control word at `$1430`.  Used to talk to the emulator.

- `proc _abort` – Terminate the program with runtime error `$36`.
  It sets `RUNERR` and calls the system STOPCODE at `$2010`.

### Date and time

- `proc _getdate` – Read the system‑date from hardware into the
  global variables `_day`, `_month` and `_year`.  The date is stored
  in binary coded decimal (BCD) in memory locations `$17B9`..`$17BB`.

- `proc _prtdate(device: file)` – Print the current date on the
  specified device (e.g. `OUTPUT` or `PRINTER`) in the format
  `day/month/year`.

### Numeric utility

- `func _getbcd(address: integer): integer` – Read a BCD encoded
  16‑bit word from the given memory address and return the unpacked
  integer.  Internally subtracts six for each nibble that exceeds nine.

- `func _abs(x: integer): integer` – Return the absolute value of
  *x*.

- `func _mod(x, n: integer): integer` – Compute *x* mod *n* via
  `x - (x div n) * n`.

- `proc _tab(x: integer)` – Output blanks until `CURPOS` exceeds
  *x*.  Used for column positioning on the screen.

- `func _random: integer` – Return a pseudo random integer in the
  range 0–255.  The generator is seeded at system startup and stored
  in memory at `$1706`.

### Text output

- `proc _prtext8(device: file; text: array[7] of char)` – Write
  eight characters contained in `text` to `device`.  The array
  indexing starts at 0, so the eight positions 0 ..7 are output.

- `proc _prtext16(device: file; text: array[15] of char)` – Write
  sixteen characters from `text` to `device`.  This is useful for
  fixed‑width labels such as filenames or headings.

PRINTING
--------
Older versions of the compiler used the control characters `PRTON`
and `PRTOFF` to switch the printer into autoprint mode.  In current
code these symbols are still defined for compatibility, but they should
no longer be used in new programs.  Instead programs should call
`writeln(@PRINTER, ...)` to send output directly to the printer
channel.
